# Abartılı Motivasyon Üreticisi

## Bu Nedir?

Bu, insanlık tarihinin en önemli bilimsel başarısıdır. NASA bile kıskanır. Bu program, sizi o kadar motive eder ki sabah 3'te kalkıp kod yazmaya başlarsınız. Veya yatağınızda daha çok uyursunuz. Bilimsel olarak kanıtlanmıştır (değil).

## Nasıl Çalışır?

Python'u çalıştırın. Rastgele abartılı Türkçe motivasyon sözleri üretir. Gerçekten çalışır. Deneyin.

```bash
python motivasyon.py
```
